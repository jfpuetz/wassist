WAssist Installer

Firmware für WAssist Node 1 · Version __VERSION__

Vor dem Anstecken: den 5-V-Logikwandler -U8 (MP1584EN) trennen. USB und 5V-Pin dürfen das DevKit nicht gleichzeitig speisen.
Dein Browser unterstützt kein Web-Serial. Bitte Chrome oder Edge am Desktop verwenden. Web-Serial braucht eine sichere Verbindung (https).

So geht's

  1. ESP32-S3 am Port „USB“ anstecken (nicht „UART/COM“).
  2. „Firmware installieren“ klicken, den Port wählen und „Install“ bestätigen.
  3. Wird kein Port angeboten: BOOT gedrückt halten, kurz RESET tippen, BOOT loslassen – dann erneut versuchen.
  4. Nach dem Flashen fragt die Seite direkt nach dem WLAN (Improv).
  5. Home Assistant findet den Node danach automatisch unter Einstellungen → Geräte & Dienste.

WLAN später ändern

Findet der Node sein WLAN nicht, öffnet er den Hotspot „WAssist Node 1 Setup“. Mit dem Handy verbinden und auf der Einrichtungsseite (sonst http://192.168.4.1) das neue WLAN eintragen.
